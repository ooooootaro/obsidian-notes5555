动物结缔组织中的主要成分， 也是哺乳动物体内含量最多、分布 最广的功能性蛋白

特点：良好的生物相容性和抗原性， 以及良好的可塑性

应用：
- 组织工程支架（皮肤移植物） 
- 作为药物、因子、细胞的载体 
- 生物补片 （辅助性）

##### 衍生物（降解产物） [[Gelatin 明胶]]


# TE
- **基本性质**：
    - 体内最丰富的蛋白质(占全身蛋白质的50%wt)
    - Ⅰ、Ⅱ和Ⅲ型胶原蛋白最为丰富
    - Ⅰ型构成人体所有胶原蛋白的90%
    - 主要由成*纤维细胞*合成
- **结构特点**：
    - 胶原蛋白最普遍的单元结构特征是三螺旋结构
    - 通过氢键与其它蛋白和多糖相互交织成网状结构
    - 产生一定的机械结构强度（纖維排列整齊）
    - *提供[[整合素  integrins]]識別位點（例如 [[RGD]]）*
- **胶原纤维的多级结构**：
    - 按照机械应力线排列以确保用最少的材料达到最大的抗拉力强度
    - 根据相同截面积比较抗拉力强度相当于钢的结构，按照每单位重量比较则优于钢的三倍
- **胶原纤维自组装过程**：
    - 最终形成的胶原纤维结构大，在细胞内不能完全组装
    - 必须在细胞外空间分泌原胶原，然后自组装成成熟纤维
    - 在细胞内，将原胶原分子的前肽剪切，更利于胶原分子组装成原纤维（直径10-300nm）
    - 原纤维进一步组装形成更大的纤维（最终直径为0.5-3μm）
- **不同类型胶原蛋白的功能分布**：
    - 胶原蛋白类型Ⅰ：皮肤，肌腱、血管、器官、骨(骨的主要成分)
    - 胶原蛋白类型Ⅱ：软骨(软骨的主要成分)
    - 胶原蛋白类型Ⅲ：真皮、心血管、肠胃道
    - 胶原蛋白类型Ⅳ：基底膜
    - 胶原蛋白类型Ⅴ：头发和指甲
- **胶原的抗原性**：
    - 胶原肽链非螺旋的端肽在天然和变性胶原中均存在
    - 由于两个不同种类的哺乳动物中间的胶原蛋白，其整个氨基酸序列变化不是很大
    - 胶原蛋白的三螺旋区域有高度的进化稳定性，但在非螺旋的末端区域中有很大的变化性
    - 在这区域中几乎50%以上的氨基酸残基表现出种属性变化
    - 大量的研究和生产都集中在如何完全去除端肽，只要去除端肽就认为是安全的
- [[Gelatin 明胶]]：
    - 明胶是胶原分子水解得到的蛋白链或蛋白分子链碎片
    - 明胶是一个具有一定分子量分布的多分散体系
    - 其分子量分布因工艺条件不同而有所差别，并影响到明胶的理化性能
- **胶原蛋白和明胶在组织工程中的应用对比**：

| 特性       | 胶原蛋白    | 明胶        |
| -------- | ------- | --------- |
| 生物相容性    | 良好      | 良好        |
| 抗原性/免疫源性 | 具有一定抗原性 | 较低        |
| 细胞结合位点   | 具有      | 具有        |
| 水溶性      | **差**   | 良好        |
| 力学性能     | 优异      | 较差，需添加交联剂 |
| 可塑性      | 良好      | 温敏性，可塑    |


P.s.
> 胶原是成分，胶原蛋白是营养

如果是考试写“骨组织的主要有机成分”，建议写：
> **胶原（主要为I型胶原）**，显得更专业。  
> 当然写“胶原蛋白”也不会错，但没那么精准。
