
- 肌梭 Muscle Spindle
    - 位于肌肉内平行于肌纤维
    - 监测肌肉长度变化
    - 参与伸张反射和姿势控制


- **腱器官(Golgi Tendon Organ: Structure and Function)
    - 位于肌腱中
    - 监测肌肉张力
    - 保护肌肉免受过度拉伸

- **γ运动神经元作用** (Function of γ-Motor Neurons)
    - 调节肌梭敏感性
    - 维持肌梭在不同肌肉长度下都能有效监测长度变化，保证运动控制的精确性
    - γ运动神经元兴奋程度越高 → 外力牵拉肌梭越容易引起兴奋
    - **作用机制**
		1. γ神经元发出传出冲动
		2. 导致梭内肌纤维两极区收缩变短
		3. 牵拉梭内肌纤维的中心区
		4. 使Ia感受末梢的发放增强
		5. 提高感受末梢对牵拉刺激的敏感性
		6. 兴奋经肌梭传入纤维传入中枢
		7. 兴奋α运动神经元



| 特征       | 肌梭 (Muscle Spindle)          | 腱器官 (Tendon Organ)       |
| -------- | ---------------------------- | ------------------------ |
| **外形特点** | 长梭状，中部膨大，两端缩小                | 纤细包囊状结构                  |
| **大小**   | 长 4-10mm                     | 长约1mm，直径约0.1mm           |
| **位置**   | 肌肉内部                         | 肌肉和肌腱接头处                 |
| **连接方式** | 与肌纤维平行（**并联**）               | 与肌纤维**串联**               |
| **包囊结构** | 结缔组织包囊                       | 纤细包囊                     |
| **内部纤维** | 梭内肌纤维（特化肌纤维）                 | 发辫样交织的胶原纤维               |
| **神经支配** | 有髓鞘感觉神经轴突                    | Ib传入纤维                   |
| **神经末梢** | 失去髓鞘，缠绕在梭内肌纤维上               | 脱去髓鞘，分支穿行于胶原纤维中          |
| **激活机制** | *梭内肌纤维被牵拉 → 神经缠绕变紧 → 离子通道开放* | *肌腱牵拉 → 胶原纤维拉直 → 挤压神经末梢* |
| **感受内容** | 肌肉长度变化                       | 肌肉张力变化                   |
| **主要作用** | 调节骨骼肌活动                      | 保护肌肉免受过度张力损伤             |
| **参与反射** | 牵张反射（**兴奋性**）                | 腱反射（**抑制性**）             |
| **典型例子** | 膝跳反射中的感受器                    | 防止肌肉撕裂的保护机制              |
| **形象记忆** | "测长尺" - 测量肌肉长短               | "压力计" - 监测肌肉张力           |
| **记忆口诀** | 梭测长度，并联排列                    | 腱测张力，串联保护                |

**功能逻辑**：

- 肌梭：感受到拉伸 → 告诉大脑"需要收缩" → 兴奋
- 腱器官：感受到过度张力 → 告诉大脑"危险，停止" → 抑制


- 等长收缩：推墙壁（用力但墙不动）
- 等张收缩：举哑铃上下运动（重量不变但肌肉长度变）

**长收缩**（肌肉用力但不变长）：

- 肌梭：长度没变 → 传入不变
- 腱器官：张力增加 → 传入增加

**等张收缩**（肌肉缩短但张力恒定）：

- 肌梭：长度缩短 → 拉伸减少 → 传入减少
- 腱器官：张力恒定 → 传入不变



## 记忆要点

**对比记忆法**：

- 肌梭：长梭形 → 测长度 → 并联 → 兴奋性反射
- 腱器官：小包囊 → 测张力 → 串联 → 抑制性反射

**功能联想**：

- 肌梭像弹簧测力计的**长度刻度**
- 腱器官像弹簧测力计的**压力表盘**




被动牵拉的阈值差异

**逻辑理解**：

- 肌梭：阈值高但先兴奋（对长度变化专门负责）
- 腱器官：阈值低但后兴奋（对张力变化专门负责）
	专门检测张力变化，被动拉伸时张力变化不明显（如医生检查时拉的）
