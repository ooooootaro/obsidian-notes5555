Bone Morphogenetic Protein
属于 **TGF-β 超家族** 的生长因子，在胚胎发育、器官形成、组织再生中发挥多种作用


| 场景             | BMP 的作用                                  |
| -------------- | ---------------------------------------- |
| 🧠 **神经发育阶段**  | 高浓度 BMP 抑制外胚层向神经细胞发展 → 转向表皮细胞            |
| 🦴 **成骨/再生医学** | BMP（尤其 BMP2、BMP7）诱导 MSCs 分化为[[骨细胞#成骨细胞]] |
| 🩹 **组织修复**    | 调节细胞增殖、迁移，促进愈合、骨整合等                      |


### 神经

- BMP是**抑制神经系统形成**的关键信号
    
- 外胚层
	- **高 BMP 信号**作用下 → **分化为上皮细胞（表皮）**
	- **BMP 信号被抑制** → 走向**神经命运（neural fate）**



[[胚孔背唇]]的信号分子(如Chordin、Noggin、Follistatin)可**拮抗**腹部化信号(如BMP4)，
从而使其附近的外胚层细胞朝预置的神经命运发育
