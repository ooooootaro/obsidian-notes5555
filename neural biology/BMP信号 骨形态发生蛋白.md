Bone Morphogenetic Protein
属于 **TGF-β 超家族** 的多功能生长因子，在胚胎发育、器官形成、组织再生中发挥多种作用


常见应用方式：与支架复合、微球控释、水凝胶包裹 

序贯作用举例：*BMP 诱导成骨分化 → TGF-β 促进增殖与骨基质成熟*

| 场景             | BMP 的作用                                            |
| -------------- | -------------------------------------------------- |
| 🧠 **神经发育阶段**  | 高浓度 BMP4 抑制外胚层向神经细胞发展 → 转向表皮细胞                     |
| 🦴 **成骨/再生医学** | BMP（尤其 BMP2、BMP7）诱导 [[MSCs 间充质干细胞]]分化为[[骨细胞#成骨细胞]] |
| 🩹 **组织修复**    | 调节细胞增殖、迁移，促进愈合、骨整合等                                |




# 神经

- BMP是**抑制神经系统形成**的关键信号
    
- 外胚层
	- **高 BMP 信号**作用下 → **分化为上皮细胞（表皮）**
	- **BMP 信号被抑制** → 走向**神经命运（neural fate）**


##### 胚胎调控机制：
[[胚孔背唇]]（诱导区域）的信号分子(如Chordin、Noggin、Follistatin)
可**拮抗**腹部化信号(如BMP4)
使得附近的外胚层细胞**不会变成表皮细胞**，而是开始**发育为神经系统（神经板）**
