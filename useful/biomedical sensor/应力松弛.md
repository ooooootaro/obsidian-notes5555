> 材料受到恒定形变量时，内部应力**会逐渐降低**


水凝胶不像金属那样刚性保持，
而是像果冻一样：挤压之后可以**慢慢“释放压力”**



- 应力松弛时间（τ₁/₂）：应力松弛为初始应力的1/2所需的时间
- 应力松弛越快，交联可逆性越强，越有利于促进成纤维细胞的扩散和增殖
- 促进[[MSCs 间充质干细胞]]的成骨分化


### 💡 为什么它是优点？

| 优点         | 原因                       |
| ---------- | ------------------------ |
| ✅ 有利细胞迁移   | 松弛的支架结构更容易被细胞“挤开”，细胞能钻进去 |
| ✅ 支持细胞增殖   | 柔顺结构减少机械应力屏蔽，有利细胞扩张      |
| ✅ 模拟真实 ECM | ECM 本身也有应力松弛，尤其在软组织中     |
| ✅ 可调节分化方向  | 松弛程度影响干细胞力学感知与命运选择       |
